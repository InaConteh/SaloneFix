# Research and Evaluation Protocol

**Project:** SaloneFix  
**Current phase:** Human-First Foundation Launch  
**Next phase:** Human-Only Operational MVP and Baseline  
**Future phase:** Hybrid Human + AI Assistance  
**Scope:** Freetown public-service reporting prototype

## 1. Evaluation sequence

### Stage A: Foundation evaluation

Test whether the designed workflow is understandable, secure, and technically complete.

### Stage B: Human-only baseline

Run the complete workflow without AI. Measure human performance and workload.

### Stage C: Hybrid comparison

Add controlled AI recommendations and compare human-only versus human-plus-AI assistance.

## 2. Dataset

Use approved controlled cases, consented anonymized examples where available, and clearly labelled edge cases. Separate real, controlled, and synthetic data in the results.

## 3. Labels

Label category, location usability, duplicate status, evidence sufficiency, routing suitability, and resolution-evidence validity. Use at least two reviewers where possible. Record disagreements and adjudication.

## 4. Human-only metrics

- Report completion rate.
- Median review time.
- Reviewer agreement.
- Correct category rate.
- Correct routing rate.
- Duplicate identification rate.
- Clarification rate.
- Resolution-evidence agreement.
- Dispute rate.
- Audit completeness.
- Usability score.

## 5. Hybrid metrics

Compare the same cases and tasks. Add:

- AI recommendation accuracy.
- Human correction rate.
- Time saved or added.
- False-positive change.
- Escalation change.
- Cost and latency.
- Performance by category and data quality.

## 6. Interpretation rule

Do not claim that the system determines truth. Report whether the workflow improves precision, traceability, consistency, or operational usefulness within the tested conditions.
